## Контрольные вопросы

**Чем база данных отличается от схемы PostgreSQL?**
База — отдельное хранилище со своими системными каталогами, в одном
подключении доступна только одна база. Схема — пространство имён внутри базы.
Объекты разных схем доступны в одном запросе через `схема.таблица`, обращение
к другой базе требует нового подключения.

**Почему внешние ключи удобнее добавлять после массовой загрузки CSV?**
При активном ключе проверка идёт на каждой вставляемой строке, что замедляет
импорт, и становится критичным порядок загрузки файлов. Добавление после
импорта проверяет весь набор один раз.

**Чем COPY отличается от psql-команды \copy?**
`COPY` выполняется сервером и читает файл в его файловой системе, требует прав
суперпользователя или роли `pg_read_server_files`. `\copy` читает файл на
стороне клиента и передаёт данные по протоколу подключения. В Docker пути
сервера и клиента различаются, поэтому каталог с CSV смонтирован в контейнер.
