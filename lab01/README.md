## Контрольные вопросы

**Чем база данных отличается от схемы PostgreSQL?**
База — отдельное хранилище, при подключении выбирается одна база.
Схема — папка для таблиц внутри базы. Таблицы из разных схем можно
использовать в одном запросе (`olist.orders`, `lab.test`), а для другой базы
нужно новое подключение.

**Почему внешние ключи удобнее добавлять после массовой загрузки CSV?**
Если ключ уже есть, СУБД проверяет каждую вставляемую строку, и загрузка
идёт медленно. Ещё приходится соблюдать порядок: сначала `customers`, потом
`orders` и т. д. Если добавить ключ после загрузки, проверка проходит один раз
по всем данным.

**Чем COPY отличается от psql-команды \copy?**
`COPY` выполняет сервер, поэтому файл должен лежать на сервере, и нужны
особые права. `\copy` выполняет psql: он читает файл на моём компьютере и
отправляет данные на сервер. У меня сервер в Docker, поэтому папка с CSV
подключена в контейнер, и `COPY` видит файлы по пути `/data/olist`.
