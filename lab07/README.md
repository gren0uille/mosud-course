## Контрольные вопросы

**Почему NULL = NULL не даёт TRUE?**
NULL — неизвестное значение. Равны ли два неизвестных, неизвестно, поэтому
результат UNKNOWN. Для сравнения, где NULL считается равным NULL, есть
`IS NOT DISTINCT FROM`.

**Как предикат в WHERE влияет на строки внешнего соединения?**
Строки без пары имеют NULL в столбцах правой таблицы. Условие на эти столбцы
в `WHERE` даёт UNKNOWN, и строки отбрасываются — LEFT JOIN превращается в
INNER JOIN. Чтобы этого не было, условие на правую таблицу пишут в `ON`.

**Почему NOT EXISTS устойчивее NOT IN при NULL?**
`x NOT IN (a, NULL)` раскрывается в `x <> a AND x <> NULL`. Второе сравнение
всегда UNKNOWN, поэтому всё условие не бывает TRUE, и результат пустой.
`NOT EXISTS` проверяет, есть ли совпавшая строка. Строка с NULL ни с чем не
совпадает и просто не находится.
