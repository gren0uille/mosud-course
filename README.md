# mosud-course

Практическая работа по МОСУД на наборе Brazilian E-Commerce Public Dataset by Olist.

CSV-файлы в репозиторий не входят, их нужно положить в `data/olist`
рядом с каталогом проекта. Источник: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

| № | Работа |
|---|---|
| 1 | Развёртывание PostgreSQL и загрузка Olist |
| 2 | Множества и мультимножества в SQL |
| 3 | Выборка, проекция, переименование и реляционная алгебра |
| 4 | Соединения отношений и сложные JOIN |
| 5 | Кванторы, EXISTS и реляционное деление |
