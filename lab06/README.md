## Контрольные вопросы

**Чем коррелированный подзапрос отличается от независимого?**
Независимый подзапрос не ссылается на внешний запрос, его достаточно выполнить
один раз (общая средняя). Коррелированный использует значения текущей строки
внешнего запроса (`oi.seller_id = s.seller_id`) и логически выполняется заново
для каждой строки.

**В каких случаях EXISTS удобнее IN?**
Когда нужна проверка «есть ли связанная строка» с условием по нескольким
столбцам или с дополнительными фильтрами. И для отрицания: `NOT EXISTS`
работает правильно при NULL, а `NOT IN` при NULL в подзапросе возвращает
пустой результат.

**Почему скалярный подзапрос должен возвращать не более одной строки?**
Он стоит на месте одного значения (`x > (SELECT …)`). Если строк две, СУБД
не знает, какую брать, и выдаёт ошибку `more than one row returned by a
subquery`. Если строк нет, результат — NULL.
